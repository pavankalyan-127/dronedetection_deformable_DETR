# 🚁 Drone Object Detection using Deformable DETR
This project performs real-time object detection from drone video feeds using the pretrained Deformable DETR transformer model.

## Features
- Transformer-based detection (no dataset required)
- Upload drone video for inference
- live video detection
- capture photos while recording
- Optional output video saving
- GPU-optimized for cloud use
  
## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
